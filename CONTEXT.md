# Project Context: REACTOR Watchface

REACTOR is a premium Garmin Connect IQ watchface for AMOLED screens.

**Primary target:** Garmin Fenix 8 AMOLED (47mm, 454×454).  
**Secondary targets:** Epix Gen 2, Enduro 3, Tactix 8.

## Design Philosophy

Inspired by Nintendo Game & Watch, Casio LCD watches, industrial control panels, Nixie displays, and Braun industrial design. The objective is NOT to create a retro watchface — it's to build a **premium modern** watchface with **retro industrial aesthetics**.

## Architecture Overview

```
ReactorApp → ReactorView → [HeaderWidget, ChartWidget, TimeWidget, FlankWidget, BottomMetricsWidget]
                              ↑
                         ThemeConfig ← properties.xml (user settings)
                              ↑
                         DataProvider ← Garmin SensorHistory / ActivityMonitor
```

### Rendering Pipeline (every onUpdate cycle)

1. `DataProvider.updateMetrics()` — reads sensor data
2. `ThemeConfig.loadProperties()` — reads user settings
3. `dc.clear()` — AMOLED black background
4. Each widget draws itself using `(dc, dataProvider, themeConfig)`

### Key Design Decisions

- **Two digit rendering paths:** Nixie bitmaps (`Theme.THEME_NIXIE_CYAN`) with simulated wire mesh and glow vs. SegmentRenderer LCD segments (all other themes).
- **Theme colors apply to:** TimeWidget digits + ChartWidget bars. Header, flanks, and bottom metrics stay fixed to maintain visual identity.
- **Zero allocations in draw loop:** All bitmaps and resources are cached on first load. Renderers reuse primitives instead of creating new objects.
- **Single theme setting:** `themeStyle` (0–5) replaces the old separate `digitStyle` + `themeColor` settings.
- **Dynamic Chart Styles:** The top dual charts support 5 different independent rendering styles (Solid, Dot Matrix, Stepped Line, Oscilloscope, LCD Outline) rendered procedurally.
