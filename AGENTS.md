# REACTOR

REACTOR is a premium Garmin Connect IQ watch face.

## Design principles

This project is inspired by:

- Nintendo Game & Watch
- Casio LCD watches
- Industrial control panels
- Nixie displays
- Braun industrial design

The objective is NOT to create a retro watchface.

The objective is to build a premium modern Garmin watchface with retro industrial aesthetics.

## Architecture

Priorities:

1. Extremely low battery consumption
2. Clean architecture
3. Modular rendering
4. High readability
5. Easy theme creation

Never duplicate drawing code.

Every visual component must be independent.

## Themes

Themes must only define:

- colors
- fonts
- background
- lcd style

Never duplicate layouts.

## Rendering

Separate:

- data providers
- renderers
- widgets
- themes

## Code style

Small classes.

Single responsibility.

Readable code.

Avoid clever code.

Avoid unnecessary allocations during rendering.

Optimize for battery life.

## Target

Primary target:

Garmin Fenix 8 AMOLED.

Secondary targets:
 
- Epix Gen2
- Enduro 3
- Tactix
