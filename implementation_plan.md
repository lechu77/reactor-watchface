# Themes Implementation Plan

## Goal
Implement 5 classic retro tech color themes (Cyan, Green Phosphor, Amber, White, Siemens Teal) that **only** affect the `TimeWidget`. All other widgets (Charts, Flanks, Bottom Metrics) will remain locked to the primary UI color (Cyan) to maintain the watch's core identity.

## User Review Required

> [!WARNING]
> **El problema de los Bitmaps (Nixie Tubes)**
> Actualmente tenemos la opción `digitStyle` que permite cambiar entre los "Dígitos Geométricos" y los "Tubos Nixie (VFD)". 
> El problema es que los Tubos Nixie son **imágenes estáticas (bitmaps)** que están pre-dibujadas en color Cyan. No puedo cambiarles el color por código a verde, ámbar o blanco. 
> 
> **¿Cómo querés proceder?**
> 1. Eliminamos los bitmaps por completo y usamos **solo** los números geométricos (que sí podemos pintar de cualquier color por código y encajan perfecto con la onda industrial).
> 2. Dejamos los bitmaps, pero si el usuario elige otra fuente de color (ej. Ámbar), los bitmaps seguirán viéndose Cyan.
> 3. Genero todas las imágenes Nixie en los 5 colores diferentes (esto sumará bastante peso a la aplicación).
> 
> Recomiendo fuertemente la **opción 1**.

> [!IMPORTANT]
> **Fondo (Background)**
> Asumo que todos estos nuevos temas utilizarán el **fondo negro puro (AMOLED)**, ya que el fósforo verde, ámbar y demás brillan sobre pantallas oscuras. Las viejas opciones de fondo gris/verdoso LCD las voy a eliminar para mantener el look premium AMOLED. ¿Estás de acuerdo?

## Proposed Changes

### `Theme.mc`
- Remove old LCD styles.
- Add `THEME_CYAN`, `THEME_GREEN_PHOSPHOR`, `THEME_AMBER`, `THEME_WHITE`, `THEME_SIEMENS`.
- Update `getPrimaryColor()` to return:
  - Cyan: `0x5ED7D2`
  - Green Phosphor: `0x43E038`
  - Amber: `0xFFB000`
  - White: `0xFFFFFF`
  - Siemens: `0x00A3A3`
- `getBackgroundColor()` will always return `COLOR_BG` (Black).

### Widgets (ChartWidget, BottomMetricsWidget)
- Modify them so they ignore `theme.getPrimaryColor()` and hardcode them to `Theme.COLOR_LCD_CYAN` (or `Theme.COLOR_ICONS`) so they don't change color.

### `settings.xml` & `properties.xml`
- Remove the old `digitStyle` if we drop bitmaps.
- Add the new `themeColor` list property.
